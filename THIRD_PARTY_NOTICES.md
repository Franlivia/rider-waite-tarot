# Third-party artwork / 第三方图像说明

The MIT license in this repository applies to original project code, templates,
and documentation. It does not relicense the historical tarot images in
`assets/artwork/*.webp`.

The screenshots and recorded animation in `docs/media/` show the same historical
artwork inside the project's interface. The artwork credits and source-status
statements below apply to those depictions as well.

## Rider–Waite–Smith, 1909 Roses & Lilies

- **Face artwork:** Pamela Colman Smith (1878–1951), published in 1909.
- **Scans:** Saskia Jansen, from her personal collection, hosted on Wikimedia Commons.
- **Card back:** the historical blue-and-white Roses & Lilies design. The Commons
  source credits an unknown author, possibly Pamela Colman Smith; its scan was
  rotated and cropped upstream.
- **Source status:** the linked Wikimedia Commons file pages identify the images
  as public domain. Face pages use Public Domain Mark / PD-old-70-expired; the
  back page provides PD-US-expired and a source-country UK public-domain basis.
  These are the source pages' status statements, not a new license granted by
  this project.
- **Mirrors:** some face images were downloaded from Arcanebra, whose methodology
  lists the same 78 Commons source files. Mirrored bytes may differ from original
  scan bytes; the manifest records the actual download URL separately.
- **Project transformations:** aspect-preserving resize to 150 px width, WebP
  encoding at quality 42, method 6. No generative image editing, recolouring, or
  additional cropping.

See [assets/artwork/sources.json](assets/artwork/sources.json) for all 79 files,
source pages, original-source metadata, download locations, and SHA-256 hashes
of the distributed WebP files. Original scan checksums and output checksums
describe different files and should not be compared as if they were identical.
